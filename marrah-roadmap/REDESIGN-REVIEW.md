# Navigation and visual redesign

27 October 2026. Scope: showcase presentation only. Merchant MVP, research JSON, financial engine and downloadable research files unchanged.

## Before

Captured current public roadmap at 1440 × 1000 before implementation. The document measured 15,595 CSS pixels vertically. Four header links served nine report sections. The roadmap's first viewport was dominated by paragraphs, hour ranges and acceptance text.

Preserved: Marrah wordmark, ivory/ink/terracotta palette, English and Arabic typography, source IDs, original chapter hashes, financial assumptions, deep research, accessible native controls and downloadable material.

## Changes

- Ten chapter views including a visual overview; one visible by default.
- Persistent desktop index; compact mobile chapter selector; previous/next controls.
- Searchable native chapter dialog with Ctrl/Command+K, keyboard traversal, Enter activation, Escape and focus return.
- Browser history and shared locale, perspective, market, sector, scenario and model inputs remain synchronized.
- Six visual overview tiles, country selector atlas and shorter chapter headings.
- Receipt-to-reward concept with manual steps and user-started playback. No live QR, order, message or reward. A stamp appears only at the verified-purchase concept step.
- Clickable G0–G5 diagram displays G3/G4 as parallel options and labels every gate as proposed.
- Merchant contribution bridge uses the existing financial engine; displayed whole-AED arithmetic is marked approximate.
- Detailed comparisons, stack options, budgets, acceptance criteria and source catalogue use progressive disclosure. Full research PDF and workbook remain available.

## Verification

Reviewed English desktop and Arabic mobile at 1440 and 375 pixels, including concept, gate diagram, economics, overview tiles and chapter selector. Inspected visible element bounds as well as document width, so overflow clipping could not conceal a layout defect. Functional suite covers ten routes, history, shared state, keyboard search, print reveal/restore, data controls, simulation, evidence, downloads, errors and reduced motion. Financial parity tests remain unchanged.

Motion uses bounded transform/opacity feedback, a user-started finite story and a single stamp response. No scroll event animation driver, continuous layout animation, animated blur or external animation runtime. Playback stops when hidden, offscreen, paused or destroyed. Reduced motion disables entrance and stamp effects. Assistive-technology certification and a physical-device matrix remain outside this browser review.
