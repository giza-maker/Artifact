# MAWJ investor concept

Published through the existing `giza-maker/Artifact` GitHub Pages setup: root of `gh-pages`, with MAWJ under `mawj/`.

Public URL: https://giza-maker.github.io/Artifact/mawj/

Static deployment includes English/Arabic landing page, interactive salon-booking mockup, 12-slide investor brief with Arabic translation, and economics calculator. All bookings and payments are simulated. Providers, ratings, prices and appointment times are fictional.

Working brand, commission rate and financial figures remain planning assumptions. Founder reports an existing business and technical team; names and credentials remain to add. Funding amount remains undecided; SAR 900,000 is an illustrative pilot budget.

No build or backend required. Paths are relative to this folder so existing sibling artifacts remain independent. Reviewed source is in the local `mawj-investor/dist` project; `.git`, hosting credentials, private hosting metadata and QA outputs are excluded from this public deployment.
