# MAWJ investor concept

Published through the existing `giza-maker/Artifact` GitHub Pages setup: root of `gh-pages`, with MAWJ under `mawj/`.

Public URL: https://giza-maker.github.io/Artifact/mawj/

Static deployment includes a redesigned English/Arabic mobile-app landing page, interactive phone mockup, 12-slide investor presentation, and economics explorer. The phone supports discovery/search, service and audience/budget filters, saved venues, service/professional/date/time/payment selection, confirmation, bookings, and reset. All bookings and payments are simulated. Providers, ratings, prices and appointment times are fictional.

Working brand, commission rate and financial figures remain planning assumptions. Founder reports an existing business and technical team; names and credentials remain to add. Funding amount remains undecided; SAR 900,000 is an illustrative pilot budget.

No build or backend required. Fonts, official Tabler icons and optimized generated photography are local. Paths are relative to this folder so existing sibling artifacts remain independent. The working copy is this `mawj/` directory; a copy is kept in local `mawj-investor/dist`. Hosting credentials, private metadata and QA screenshots are excluded from public deployment. See DESIGN.md and standards-sources.md for tokens and provenance.
