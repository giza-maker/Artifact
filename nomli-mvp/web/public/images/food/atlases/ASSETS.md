# Supermarket food artwork

Generated 28 October 2026 with built-in ImageGen. Seventeen transparent 4 × 4 atlases, 272 food illustrations; 32 editable supermarket categories. Full prompt set, row-major mapping, dimensions, file sizes and SHA-256 hashes: [MANIFEST.json](MANIFEST.json). Catalog and bilingual aliases: content/food-art-catalog.json.

Each generated source was packaged as lossless WebP without resizing, cropping, color changes or loss of transparency. Alpha bytes and visible pixels over black and white backgrounds were verified identical. Original PNGs remain in Codex generated_images. All runtime artwork is bundled offline.

Uploaded local item photos take priority. Exact known product types use specific artwork; unmatched items use category representatives or the legacy basket. This library covers common food types across supermarket sections, not every branded SKU. These illustrations do not establish food identity, ingredients, allergens, package size, storage safety or expiry. Cooking links remain separately confirmed.
