Design read: Saudi merchant service, Arabic first, familiar and confident. White surface, recognisable green family, actual shop-context photography and custom wordmark. Native HTML/CSS/JS retained; no framework migration or UI package required. Design variance 7, motion intensity 2, visual density 3.

- Colors: white #ffffff, ink #103928, green #25d366, pale #e6ffda, soft #f5f9f3, muted #5a7063, line #dce7dc. One green family. CTA ink contrast 6.46:1; muted white contrast 5.34:1.
- Type: self-hosted Alexandria variable for Arabic; self-hosted Manrope for English/numerals. Licenses and font/icon sources under dist/assets/. Custom wordmark is an actual generated raster asset, not a font approximation or handcrafted SVG.
- Shape: image frame 32px desktop /22px mobile; outer workshop22, message17, CTA11. Compact brand glyph from Arabic mim, not a WhatsApp logo.
- Layout: max1440,4.2% desktop gutters/6%mobile. Header96px desktop,76pxmobile. Hero asymmetric split, two-line heading and contextual photography. Four-stage navigation strip, editable sector example, linear process rows, calculator, scoped pricing, native FAQs and final action.
- Motion: button2px hover and small details disclosure rotation only. Reduced-motion disables transitions/transform.
- Assets: generated wordmark, compact mark, and checkout photo. Hero WebP about180kB. Fonts local. Tabler outline icons, MIT. Do not replace real visual assets with code drawings.
- Native dialogs, visible focus, labeled inputs and linked budget errors. Pilot download local JSON; no false booked/sent state. No tracking or external font requests.
- Keep visit-proof, consent, neutral-review, cost and pilot-maturity caveats. All imagery and examples illustrative. No performance guarantee or partnership claim.
- Publication target: the existing giza-maker/Artifact GitHub Pages repository, under /muwalif/. Keep unrelated published projects intact.
- Baseline-ui/create-design-md found under retired installed skills. Compatible preflight constraints applied; existing vanilla stack and tokens retained.
- Film surface: ink band after the journey strip, pale kicker, white balanced heading, restrained player frame (24px desktop / 20px mobile). Header secondary action links to this section. Video controls are native, with an accessible branded start button.
- Media: approved 58-second landscape and separately composed portrait films, self-hosted with relative paths. Select portrait at up to 600px before first playback. Keep the selected format after playback begins. No autoplay or upfront MP4 fetch; show a local poster first.
- Captions: approved Arabic remains in the film; native English subtitles activate in the English page view. Keep a direct-video fallback for playback failures.
