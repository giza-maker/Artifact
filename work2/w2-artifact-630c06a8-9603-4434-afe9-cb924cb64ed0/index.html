How it works

Three-tier budget
escalation — by design.

BLOCKS enforces graduated token budgets. Each tier tightens the ceiling and escalates the alert posture. Verification runs inline — no sidecar, no latency cliff.

⬜

Tier 1 — Advisory

A soft warning fires when output approaches 70% of the declared budget. Signals are logged and surfaced in the harness dashboard without blocking generation.

🟨

Tier 2 — Throttle

At 90% consumption the harness injects a stop-sequence hint into the active context window, nudging the model to wrap within the remaining budget.

🟥

Tier 3 — Hard Ceiling

At ceiling breach, generation is terminated and a structured escalation record is emitted — complete with token counts, tier reason, and truncation offset.

📊

Real-time Telemetry

Every token event streams to the harness bus. Live meters track budget burn rate, tier transitions, and cumulative overflow attempts across all active requests.

🔁

CI/CD Integration

A pass/fail exit code on every test run. Compare budgets across model versions, commit SHAs, or prompt variants — regression detection built in by default.

⚙️

Per-task Configuration

Override global ceilings at the task, agent, or pipeline level. YAML, environment variables, or programmatic API — whichever fits your infra.
